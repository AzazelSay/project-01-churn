git add . — добавить изменения в подготовку к коммиту
git commit -m "..." — сохранить эти изменения в истории Git
git push — отправить их на GitHub

git status покажет:
    * какие файлы изменены
    * что будет закоммичено
    * нет ли лишнего

Если ты изменил только один файл, можно добавить только его, а не всё сразу:
git add app.py
git commit -m "Исправил ошибку в app.py"
git push
